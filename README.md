# SZ TradingTerminal 📈

**SZ TradingTerminal** — десктопный торговый терминал для аналитики внутриигрового аукциона игры
**STALZONE**. Помогает трейдеру быстро оценивать справедливую цену предмета, ловить выгодные лоты, 
отслеживать историю цен и вести учёт собственных сделок.

> ⚠️ Приложение работает **только на Windows**. Это независимый аналитический инструмент, официально
> не связанный с EXBO.

Обе ссылки ведут на актуальную версию и не меняются от релиза к релизу. Полный список версий — на

По умолчанию (без прав администратора) устанавливается в `%LocalAppData%`. Дальше приложение
обновляется автоматически при каждом входе — вручную ничего скачивать не нужно, независимо от того,
каким из двух способов вы его установили.

### ⚠️ Про предупреждение Windows SmartScreen при первом запуске

При первом запуске `Setup.exe` Windows Defender SmartScreen скорее всего покажет
«Windows защитила ваш компьютер» / «Неизвестный издатель». 
Это ожидаемо, однако файл не заражён, а требует цифровую подпись файла (Authenticode-сертификатом)
Получить такой сертификат для приложения из России сейчас нельзя технически, так как с 2022 года 
крупные удостоверяющие центры (DigiCert, Sectigo, GlobalSign и др.) не выдают сертификаты подписи
кода российским физлицам и организациям. Единственная более доступная альтернатива, сервис
Microsoft Trusted Signing, тоже недоступна: она открыта только для разработчиков и организаций 
из ограниченного списка стран (США, Канада, ЕС, Великобритания и ряд других), Россия в этот список
не входит. Свой российский удостоверяющий центр вопрос не решает — Windows ему не доверяет.

**Как убедиться, что скачали именно наш файл, а не подделку:**
- Качайте `Setup.exe` только с этой страницы или по прямой ссылке выше — не с сторонних сайтов.
- На странице [Releases](https://github.com/JrlPirate/SZ-TradingTerminal/releases) у каждого файла
  указана контрольная сумма SHA256 — при желании можно сверить её со скачанным файлом
  (`certutil -hashfile Setup.exe SHA256` в командной строке Windows).

Если всё сходится — на экране SmartScreen нажмите **«Подробнее»** → **«Выполнить в любом случае»**.

## 🚀 Ключевой функционал

* **Рынок** — поиск активных лотов с фильтрацией по рангу, заточке и цене; дерево «Избранного».
* **Инспектор предмета** — иконка с ранговой подсветкой, метрики Минимум / Медиана / Максимум за
  12 часов, 1, 3, 7, 14 и 30 дней.
* **Рыночный снайпер** — фоновый сканер аукциона: пороги на покупку/продажу, алерты звуком, всплывающим
  Windows-уведомлением и цветной строкой в «Живой ленте». Доступен на лицензиях Premium и Trial.
* **История цен** — загрузка совершённых сделок, локальная фильтрация без повторных запросов, график
  или таблица.
* **Реестр сделок** — учёт покупок и продаж, статусы «Ставка / На складе / Продано», расчёт профита
  и ROI.

## 📦 Об этом репозитории

Здесь публикуются только готовые сборки приложения — репозиторий не содержит исходного кода.
На вкладке [Releases](https://github.com/JrlPirate/SZ-TradingTerminal/releases), кроме обычных
версий терминала, есть два постоянных служебных релиза (оба помечены **Pre-release**, поэтому не
претендуют на статус «Latest»):
- `database` — капсула базы предметов, которую терминал подтягивает автоматически; скачивать вручную
  не нужно;
- `bootstrap` — установщик с мастером (см. раздел «Скачать» выше), его тоже не нужно искать отдельно,
  ссылка на него уже есть выше.
